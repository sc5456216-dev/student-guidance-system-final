# 🎓 Student Guidance System

A comprehensive platform for managing students, counseling, courses, assessments, and appointments. Built with Django, PostgreSQL, Redis, Celery, and fully containerized with Docker.

## 🚀 Features

- JWT-based authentication with SimpleJWT
- Student, Counselor, and Mentor profiles
- Course management and batch enrollment
- Academic assessments with questions and results
- Counseling session scheduling and management
- Appointment booking system
- Real-time notifications (email + in-app)
- Celery background tasks for async email sending
- Fully Dockerized with Docker Compose

## 🛠️ Tech Stack

- Django 6.0.7
- Django REST Framework
- PostgreSQL 15
- Redis 7 (cache / broker)
- Celery 5.4 (background tasks)
- Docker & Docker Compose
